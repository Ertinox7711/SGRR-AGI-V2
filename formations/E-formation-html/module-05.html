Leçon 5.2~7 minWorkflow

Workflow image par plan (~3 min/image)

  1. Ouvrir le générateur d'images IA.
  2. Coller : décor (depuis template) + perso (depuis prompts master) + pose du plan.
  3. Générer 3 à 4 variations.
  4. Choisir la meilleure.
  5. Si moyen → regénérer SANS reformuler (souvent c'est l'aléatoire qui tranche).
  6. Télécharger → renommer PLAN-XX-NOM-emotion.png → ranger dans 02-IMAGES/E01/.
Leçon 5.3~9 minFixes

Erreurs fréquentes & fixes

ProblèmeSolution
Texte anglais incrustéAjouter no english text, French only
Watermark / texte parasiteAjouter no text overlay
Perso méconnaissableRecoller le bloc PERSO complet depuis prompts master
Décor changeRecoller le bloc DÉCOR mot pour mot
Mauvais body typeForcer en majuscules : HOURGLASS CURVY / TALL ATHLETIC
Leçon 5.4~6 minDuo

Plans à 2 personnages

  • Demander 1 seule image avec les 2 persos cadrés.
  • Préciser les positions : left frame, right frame, facing each other.
  • Tu animeras ENSUITE deux fois la même image pour faire parler chacun à son tour.
AstucePour les plans à 2, écrire les deux blocs perso complets l'un après l'autre. Ne pas raccourcir — la cohérence vient de la répétition mot pour mot.
