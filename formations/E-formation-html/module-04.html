Module 4 · Script

Écrire le script

Le script est ta colonne vertébrale. Bon script + animation moyenne = succès. Animation parfaite + script plat = flop.

Leçon 4.1~10 minMaster prompt

Le prompt scriptwriter master

À coller dans ton chatbot IA scriptwriter. Adapte les variables entre crochets.

Tu es scénariste téléréalité TikTok français.
Génère l'ÉPISODE [N°] de la SAISON [N°] de "[NOM_SHOW]" d'une durée de [DURÉE].

CONCEPT : [résumé 2 lignes]
PERSONNAGES FIXES : [liste casting + body types — copier depuis ton CLAUDE.md]
CONTEXTE : [résumé épisode précédent OU "épisode 1, arrivée initiale"]

STRUCTURE PAR ÉPISODE :
1. Intro présentatrice (si pertinent)
2. Scènes principales (interactions)
3. ITW présentation (uniquement épisodes 1-2)
4. ITW réaction après chaque moment clé
5. Moments collectifs (soirée, repas, piscine…)
6. Twist / événement clé
7. Réactions à chaud
8. ITW émotionnels
9. Cliffhanger

FORMAT ITW : [ITW — Prénom] confessionnal naturel.
FORMAT DIALOGUES : @PERSO [ÉMOTION + body language] : "réplique"

LONGUEUR : 2 min = 250-300 mots | 5 min = 600-750 mots
TON : argot TikTok FR dramatique + drôle, sans insultes graves.

Génère maintenant le script complet.
Leçon 4.2~8 minArc saison

La structure par phase de saison

Pour 14 épisodes, planifie en 7 phases. Chaque phase a son énergie propre.

PhaseÉpisodesÉvénement clé
IntroE01-E02Arrivées, premières tensions, premier twist
TentationE03-E04Dates secrètes, jalousies, doutes
RévélationsE05-E06Choc majeur (visionnage images cachées)
ConséquencesE07-E08Disputes, distances
AlliancesE09-E10Nouveaux duos, manipulations
Crise maxE11-E12Explosion, départ surprise
FinaleE13-E14Choix final + cliffhanger saison 2
Leçon 4.3~9 minDialogues

Écrire des dialogues qui sonnent vrai

Construis un lexique argot spécifique au show. Range-le dans 00-REFS/VOCABULAIRE/LEXIQUE.md.

Exemples d'argot validé

mondial (top) · kiffer (aimer) · seum (frustré) · frérot · go (fille) · ITV (confessionnal) · dinguerie · miskine · wesh · chelou · cramé · câbler.

Signature lexicale par perso

  • Drama queen abuse de "dinguerie / malade"
  • Manipulateur dit "frérot" + sourire
  • Mystérieuse parle 3 mots max
Mots à bannirInsultes religieuses, vulgarité sexuelle explicite → démonétisation immédiate.
Leçon 4.4~6 minPlans

Décomposer le script en plans

Après le script, demande au chatbot :

Décompose ce script en dialogues par plan.
Pour chaque plan, liste : numéro de plan, perso présent,
décor, action, réplique exacte.
Une ligne par réplique. Pas de descriptions superflues.

Tu obtiens ta liste de plans = ta to-do du jour.

Leçon 4.5~4 minHook

Le titre / hook de l'épisode

Prendre la réplique la plus choc du script → c'est ton titre.

Exemple"j'vais les FUMER 😤 | Ep.X"
  • Max 150 caractères
  • 1 emoji maximum
  • Majuscules sur le mot fort
