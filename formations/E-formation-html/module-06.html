Module 6 · Animation

Animer les plans

L'étape qui transforme tes images fixes en série. Outils vidéo IA modernes = animation + voix + lip sync + ambiance sonore en UN seul rendu.

Leçon 6.1~5 minAll-in-one

Pourquoi animation + voix + son tout-en-un

  • Les outils vidéo IA modernes génèrent animation + voix + lip sync + ambiance sonore en un seul rendu.
  • Pas besoin de générateur de voix séparé sauf cas exceptionnel.
  • Tu gagnes 70% du temps de prod vs workflow voix séparée.
Leçon 6.2~7 minRègles

Les règles ABSOLUES du prompt animation

Non-négociable
  • PAS de durée ("5 seconds", "8 seconds") → l'outil gère.
  • PAS de timestamps ("0-2s", "Beat 1").
  • PAS de "vertical 9:16" → l'outil gère.

Format dialogue STRICT

@PERSO [ÉMOTION + body language] : "réplique en français"

Toujours inclure en fin de prompt :

hyper expressive animated face,
perfect French lip sync,
cinematic CGI quality.
Leçon 6.3~6 minPrompts

Générer les prompts animation

Coller dans ton chatbot scriptwriter (même conversation que le script) :

Pour chaque plan, génère un prompt d'animation.
Règles : pas de durées, pas de timestamps, pas de "9:16".
Format dialogue : @PERSO [ÉMOTION + body language] : "réplique"
Toujours finir par : hyper expressive animated face,
perfect French lip sync, cinematic CGI quality.
Leçon 6.4~10 minWorkflow

Workflow animation par plan (5-10 min/plan)

  1. Ouvrir l'outil vidéo IA.
  2. Nouveau projet ou nouvelle génération.
  3. Uploader l'image fixe du plan en first frame.
  4. Coller le prompt d'animation correspondant.
  5. Lancer la génération.
  6. Récupérer le rendu : vidéo + voix + son tous intégrés.
  7. Télécharger → renommer PLAN-XX-NOM-action.mp4 → ranger dans 02-VIDEOS/E01/.
  8. Si le rendu est parfait → noter le seed dans 00-REFS/seeds/SEEDS.md.
Leçon 6.5~7 minRécup

Que faire en cas de rendu raté

Échec n°Action
1er échecRegénérer sans rien changer
2e échecReformuler le body language (souvent c'est ça qui coince)
3e échecRecadrer l'image fixe (la pose initiale empêche l'anim)
Watermark visibleNe PAS chercher à le supprimer dans la vidéo. Tu vas le masquer au montage avec une barre noire ou un sous-titre. Beaucoup plus rapide et propre.
